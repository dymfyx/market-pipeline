# market-pipeline

## 📖 项目简介
本项目是一个基于 Python 的 A 股多因子选股与量化回测系统。从数据源获取到策略回测，形成了一套完整的量化研究闭环。

**当前版本：v0.5**

## ✨ 核心功能
- **异步数据抓取**：使用 `asyncio` 与 `ThreadPoolExecutor` 并发抓取 A 股行情数据，内置 `Semaphore` 限流与指数退避重试机制。
- **数据清洗与质量校验**：自动校验空数据、逻辑异常（如最高价低于最低价），处理缺失值并对齐多股票时间序列。
- **多因子选股模型**：支持动量因子与低波动因子的横截面打分合成，自动选出 Top N 股票进行轮动。
- **参数敏感性测试**：支持调整调仓周期（5/10/20天）、因子权重、持仓数量等参数，并输出对比结果。
- **真实约束回测**：包含手续费、滑点计算，严格防范未来函数（`shift(1)`），支持与等权基准对比。

## 🛠️ 技术栈
- **语言**：Python 3.11+
- **数据处理**：Pandas, NumPy
- **数据源**：akshare
- **异步框架**：asyncio, concurrent.futures
- **可视化**：Matplotlib

## 📊 回测结果概览
![多因子轮动策略净值对比](https://github.com/dymfyx/market-pipeline/raw/main/Figure_1.png)

基于 2024-01 至 2026-09 的样本外数据，对沪深两市 77 只股票进行多因子轮动回测，结果如下：

| 策略配置 | 最终净值 | 等权基准净值 | 结论 |
| :--- | :--- | :--- | :--- |
| 5日调仓（80%动量+20%低波动） | 1.2719 | 1.2773 | 跑输基准，高频交易成本吞噬收益 |
| 10日调仓（80%动量+20%低波动） | 1.2175 | 1.2773 | 动量窗口错配，表现最差 |
| **20日调仓（80%动量+20%低波动）** | **1.6170** | 1.2773 | **大幅跑赢基准，参数窗口与调仓周期形成黄金共振** |

> **核心结论**：
> 1. 当因子窗口（20日动量）与调仓周期（20天）对齐时，策略表现最佳。
> 2. 低波动因子的引入在一定程度上牺牲了进攻性（对比纯动量策略），但有效平滑了回撤曲线。
> 3. 交易摩擦（手续费+滑点，单边万分之十五）对高频调仓策略影响极大。
